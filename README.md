# 후킹 제목 생성기

짤·쇼츠를 올리기 전에 매번 고민하는 **후킹 제목 · 썸네일 문구 · 플랫폼별 본문 · 해시태그**를 한 번에 뽑는 웹 도구입니다.

- 주소: **https://anchirong9-arch.github.io/hook-title-gen/**
- 빌드 없음 — `index.html` + `style.css` + `app.js` 만으로 동작합니다. 서버·로그인·설치 없음.
- 입력값·즐겨찾기·프리셋은 브라우저 `localStorage`에만 저장되고 어디로도 전송되지 않습니다.

## 쓰는 순서

1. **소재 카테고리** — 동물/반려 · 거지방/가성비 · 직장/알바/교대 · 연애/썸/달글 · 학교/시험 · 일상/병맛
2. **분위기/톤** — 킹받음/웃김 · 반전/충격 · 공감/위로 · 정보/꿀팁
3. **키워드** — 쉼표로 최대 3개 (예: `강아지, 마가렛트, 야간근무`). 비우면 카테고리 기본 키워드로 채웁니다.
4. **상품 번호** — 예: `021`
   - `프로필 링크 {번호}번 문구 넣기` → 본문에 "상품이 궁금하면 프로필 링크에서 021번!"
   - `[광고 포함] 표기 넣기` → 대가성 문구 삽입 (인스타는 `#광고` 태그)
5. **제목 뽑기**(Enter) 또는 **🎲 다시 뽑기**

## 나오는 것

- **후킹 제목 9개** — 클릭유도 / 질문 / 공감 / 정보 유형 표시, 40자 넘으면 노란색(쇼츠 제목에서 잘릴 수 있음)
- **썸네일 상단 문구 5개** — 16자 이내로 자동 다듬어서 `meme-thumb-studio` 띠에 그대로 붙여넣기 가능, 글자 수 표시
- **플랫폼별 본문 + 해시태그** — 쓰레드 / 유튜브 커뮤니티·쇼츠 / 틱톡 / 인스타, 각각 원클릭 복사
- **전체 복사** — 제목·문구·4곳 본문을 한 번에 (디코 `#피클-로그` 정리용)
- **⭐ 즐겨찾기** — 제목·문구를 담아두고 다시 복사
- **프리셋** — 카테고리·톤·키워드·상품번호 조합을 이름 붙여 저장

## 운영 규칙이 반영된 부분

- 쓰레드: 링크는 본문이 아니라 **첫 답글**에 다는 운영이라, 본문에는 프로필 링크 안내 문구만 들어갑니다.
- 틱톡: 캡션 URL은 클릭이 안 되므로 **프로필 링크 유도 문구**만 넣습니다.
- 인스타: 짤만 올리는 계정이면 본문·태그 없이 사진만 올려도 된다는 안내를 카드에 표시합니다.
- 유튜브 커뮤니티: 사진 최대 10장 제한을 카드에 표시합니다.
- 민감 소재(자살·자해·섭식장애 등)는 문구와 별개로 업로드 전 확인하라는 문구를 하단에 고정했습니다.

## URL 파라미터 (선택)

다른 도구에서 넘겨줄 때 쓸 수 있습니다.

```
https://anchirong9-arch.github.io/hook-title-gen/?cat=daily&tone=twist&kw=출근,폰&pno=021&link=1&ad=1
```

`cat`: pet · frugal · work · love · school · daily / `tone`: fun · twist · empathy · info / `link`·`ad`: `0`이면 끔
